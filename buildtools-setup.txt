Use the Visual Studio Build Tools product, not Community/Professional/Enterprise.

Official Build Tools Insiders bootstrapper:
https://aka.ms/vs/18/insiders/vs_BuildTools.exe

From Command Prompt in this project directory (use the bootstrapper's full path
if it is not available here or on PATH):
vs_BuildTools.exe --config "%CD%\cpp-gamedev-buildtools.vsconfig"

The configuration requests MSVC x64/x86, AddressSanitizer, one Windows SDK,
CMake/Ninja, and vcpkg.
Required dependencies are added automatically. Additional workloads are unnecessary.

After installation, follow README.md: setup.ps1 installs the pinned project-local
tools, and build.bat initializes the MSVC environment and builds this starter.
The first build also installs the SDL3, image, audio, and compression libraries
declared in vcpkg.json; no additional Visual Studio components are needed.
setup.ps1 also prepares Inno Setup under .tools; it is not a Microsoft Installer
component. Use build.bat release package to create the Windows installer in dist.
The full Visual Studio IDE and a separate original Warblade installation are not
required. The project's assets/ directory supplies the bundled game media.
