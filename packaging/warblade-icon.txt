Original Warblade icon

packaging/warblade.ico was copied unchanged from warblade.ico in the locally
installed original Warblade 1.34 game. It contains 16x16, 32x32, and 48x48 images.

This icon is an original game asset, not part of this project's independently
written source code. It is not covered by this project's MIT license. No separate
redistribution permission for the icon has been established by this project.

The icon is embedded into the game executable and the Windows installer.
Shortcuts use the icon embedded in warblade.exe.
